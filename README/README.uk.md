# Інструменти
## rmGimbalMonitor
### Встановлення
1) Перейдіть до розділу [Releases](https://github.com/Drendika/MayaCustomTools/releases).
2) Завантажте останню версію інструмента(rmGimbalMonitor_V2.zip).
3) Розпаковуйте файли на робочий стіл.
4) Перетягніть файл `Drug&Drop Install.py` у вікно Maya.
5) На вашій панелі інструментів має з’явитися нова іконка.
Детальний покроковий процес показано в цьому відео (посилання буде додано сюди після запису відео). 

### Особливості
Ви можете відстежувати блокування осей (gimbal lock) для будь-якого контрола будь-якого персонажа в режимі реального часу. За потреби можна створювати власні налаштування для сортування та пропуску контролів.

### Сумісність

Перевірено та підтверджено працездатність на:
- Maya 2022
- Maya 2023
- Maya 2024 / 2024.2

**Наразі не підтримується: Maya 2016-2020/2025 та новіші версії.**

### Відомі баги

- Некоректне відображення кастомних іконок розміром менше за 32x32.
- Надто довга назва категорії не вміщується у стовпці таблиці та Edit Controls.
- Після додавання кастомної іконки вона копіюється у теку `icons`, проте інструмент все одно використовує іконку, яку користувач обрав спочатку (з її початкового розташування), а не ту, що міститься в папці `icons`.

## Сніпети
### Hot reload
#### Особливості
Сніпет для швидкої розробки інтерфейсу за допомогою PySide. Hot reload видаляє всі модулі з `sys.modules`, а також закриває та видаляє вікно Qt.
#### Сумісність
Hot reload має працювати на Maya 2016 - 2027.
Перевірено та підтверджено працездатність на:
- Maya 2022
- Maya 2023
- Maya 2024
